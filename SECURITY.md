# Security

If you find a security problem in one of our packs, add-ons or tools, report it privately: open the repo's **Security** tab and choose **Report a vulnerability** ([GitHub's steps](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Please don't open a public issue for it.

Tell us the project, the edition (Bedrock or Java), the version you used, how your world or server is set up and the steps that show the problem.

Every report is read and handled in order of severity. Problems that can damage worlds or expose player data come first. You'll hear back when there's a question about your report or a fix is ready.

Fixes go into the latest release and the latest pre-release of each edition.

Worth reporting: anything that can damage or wipe a world or server, leak player data, or let a player do something they don't have permission for, like running operator commands or reaching other players' items.
