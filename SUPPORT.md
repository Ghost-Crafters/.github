## Questions

Ask in the Q&A category of the repo's Discussions tab, if the repo has one. If it doesn't, check the repo's README and guide first, then open a bug report or feature request if nothing there covers it. We don't answer questions through chat servers or forums. GitHub is the one place we read.

## Which version you're running

Every file you download carries its edition and version in the name, for example `item-magnet-bedrock-1.2.0.mcaddon`, and the Releases page it came from is tagged the same way (`bedrock-v1.2.0`). It also shows on the pack's page in Minecraft's settings screen, or in the tool's own settings screen if it has one. If you can't find it, say which Releases page you downloaded from and when.

Also note your Minecraft version and where you play (Windows, Android, console, Realms, a dedicated server, Java on desktop). The [bug report form](https://github.com/Ghost-Crafters/.github/blob/master/.github/ISSUE_TEMPLATE/bug_report.yml) asks for both.

## Logs to attach

For Bedrock, turn on the content log in Minecraft's creator settings and attach what it shows from around the time the problem happened. For a dedicated server (Bedrock or Java), attach the console output from just before and after it. For Java on desktop, attach `latest.log` from the `logs` folder of your game directory.

Read through a log before you post it and remove anything private, like your name in a file path or a server address.
