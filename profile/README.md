# Ghost-Crafters

Minecraft behavior packs, add-ons, builds and server tools. Bedrock comes first, and Java versions follow where a project makes sense on both.

Every project has a public repo with its releases, a guide and the place to report bugs. Downloads are on each repo's Releases page. Pre-releases (alpha, beta and rc) go up there too, so you can try what's coming next. Back up your worlds before you install one.

Found a bug? Open an issue in that project's repo. Security problems go through the repo's Security tab instead, so they stay private until they're fixed. The [security policy](https://github.com/Ghost-Crafters/.github/blob/master/SECURITY.md) says how.

NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.
