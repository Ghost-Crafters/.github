# Contributing

The public Ghost-Crafters repos are where releases, guides and bug reports live. They take bug reports and ideas. The code is kept in private repos, so pull requests to the public ones aren't accepted and will be closed.

## Reporting a bug

Open an issue in the repo of the pack or tool that's misbehaving and fill in the [bug report form](https://github.com/Ghost-Crafters/.github/blob/master/.github/ISSUE_TEMPLATE/bug_report.yml). It asks for the edition, the version, the Minecraft version and where you play, then what happened and how to get it to happen again. Attach the content log (Bedrock) or the server console output (Java and dedicated servers) from around that moment. [SUPPORT.md](https://github.com/Ghost-Crafters/.github/blob/master/SUPPORT.md) shows where to find the version and the logs.

Check the open issues first. If yours is already there, add what you know to it instead of opening a second one.

Security problems don't go in a public issue. Follow the [security policy](https://github.com/Ghost-Crafters/.github/blob/master/SECURITY.md).

## Ideas

Use the [feature request form](https://github.com/Ghost-Crafters/.github/blob/master/.github/ISSUE_TEMPLATE/feature_request.yml) in the same repo. Say what you're trying to do in your world or on your server, not only what you'd like added.

## How releases are named

Release tags look like `<edition>-vX.Y.Z`, where the edition is `bedrock`, `java` or `universal` and X.Y.Z is the version, for example `bedrock-v1.2.0`. Each edition is versioned on its own, so a Java release doesn't have to match the Bedrock one.

Before a release goes out, it gets pre-releases on the same Releases page: alpha first, then beta, then rc (release candidate). They're marked as pre-releases, so back up your worlds before you try one. Each release is written up with the [release notes template](https://github.com/Ghost-Crafters/.github/blob/master/RELEASE_NOTES_TEMPLATE.md).

## Conduct

Everyone in issues and discussions follows the [Code of Conduct](https://github.com/Ghost-Crafters/.github/blob/master/CODE_OF_CONDUCT.md).
