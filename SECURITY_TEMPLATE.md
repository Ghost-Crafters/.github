# Security

If you find a security problem in <Project>, report it privately through this repo's **Security** tab. Please don't open a public issue for it.

<p align="center"><a href="https://github.com/Ghost-Crafters/<repo>/security/advisories/new"><img alt="Report a vulnerability" src="https://img.shields.io/badge/Report%20a%20vulnerability-d1242f?style=plastic&logo=github"></a></p>

The form asks for a title, a description, the affected versions and, if you can judge it, a severity. In the description, tell us the edition (Bedrock or Java), the version you used, how your world or server is set up and the steps that show the problem.

Every report is read and handled in order of severity. Problems that can damage worlds or expose player data come first. You'll hear back when there's a question about your report or a fix is ready.

Fixes go into the latest release and the latest pre-release of each edition.

Worth reporting: anything that can damage or wipe a world or server, leak player data, or let a player do something they don't have permission for, like running operator commands or reaching other players' items.
